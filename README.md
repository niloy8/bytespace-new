# ByteSpace — Online Course & Creator Platform

A modern, responsive landing page and authentication portal built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**, designed with pixel-perfect precision matching the Figma specifications.

---

## 🌟 Key Features

- **Pixel-Perfect Figma Design**: 1440px canvas layout with a 120px grid system and accurate typography.
- **Hero & 3D Centerpiece**: Floating course preview cards with 3D lime assets and smooth micro-animations.
- **Interactive Course Directory**: Multi-row category filter pills and dynamic course cards with pricing and ratings.
- **Professional Growth Section**: Real-time revenue analytics cards with backdrop-blur glassmorphism.
- **Community Testimonials**: Styled community reviews with radial glow background effects.
- **Complete Auth Portal**: Split-screen **Sign In** (`/signin`) and **Sign Up** (`/join`) flows with stacked 3D graphics and social logins.
- **Vector Branding**: Crisp vector SVG favicon (`Vector.svg`) configured for all devices.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Fonts**: Satoshi (Custom Variable), Poppins, Clash Display
